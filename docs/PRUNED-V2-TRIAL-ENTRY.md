## 启动、读取和恢复

当前可运行 `node src/pruned-v2-trial-cli.js preflight`，没有配置时只输出未获授权 proposal，不创建数据目录、不读 Key、不发请求。默认目录沿用同一个仓库外 trial Store；也可用 `--data-dir` 指定同一外部 Store。不同路径若没有完整旧批准/账项就不能初始化。

未来收到明确的新授权后，init 必须同时提供预算、精确 case、虚构外发和两笔旧占用保留的确认；缺任一项拒绝。新额度显式绑定新版本，旧额度不能复用。重复 init 不重置、改额度或刷新有效期，配置改动拒绝。

`run` 必须显式 `--live`，所有配置、来源、旧占用和预算在访问环境 Key 前检查，并在同一个 owner lock 下复核。完成后的 `read`/重复 run 可无密钥重放，零额外请求。已提交场景中断后需要显式 `--resume`，只继续剩余阶段；unknown 拒绝继续。取消/删除/撤回阻断；撤回后仍可查看脱敏账目，正文与读取视图为空，旧占用不释放。失败和取消的错误信息沿用固定安全词汇，不打印任意异常或 Key。

不在本文件提供可直接触发付费的整段命令。授权后才交付完整 PowerShell 块，安全输入 Key，finally 清除环境变量。没有更换模型/HTTP/输出限额/重试次数的 CLI 参数。

## 验证与限制

测试用临时仓库外 Store、独立虚构账项和本地 HTTP simulator，没有真实请求。新增入口用例检查未批准不写盘、精确授权/旧占用、不可变额度、CLI 参数及无 Key 阻断、场景清理计数、三阶段/重放/上限、失败/取消、实际进程退出和显式恢复、owner lock、撤回/过期。共享预算核心的故障注入证据沿用前阶段，非重复声称全部在入口测试中覆盖。

首轮定向 9/11：一项测试误期待优先报旧质量未完成，实际先拒绝缺少旧批准文件；另一项暴露撤回清理旧失败正文后只读检查被误阻断。修正断言与 revoked 读取分支后 11/11；又增加两项入口隔离/中断测试。最终范围和直接输出见 `docs/validation/pruned-v2-entry.*`，不隐藏开发失败。

同作者复查，不是独立审计。假输出只能证明机制；真实协议遵循、语义支持、实际 tokens/费用和梦境质量仍待评估。未使用用户真实梦簿或私人材料；公开只放代码、独立虚构测试和聚合证据。存储/备份边界沿用合同：受管理文件和撤回日志负责清理，已交付副本、外部备份、终端、供应商保存与物理擦除不由首版自动处理。Asteria 适配器仍待对接。
