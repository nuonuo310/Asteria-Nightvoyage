# 有限引文归一化 v2：模拟实现

评审结论：采用“仅移除已校验但未被使用的引文”作为独立版本的候选合同，**不改当前真实协议**。本阶段已实现并在本地模拟闭环验证；未接入付费客户端、未初始化新额度、未调用真实模型。

## 与旧版本的区别

协议身份为 `offline-compact-quotes-v2-pruned-unused`，归一化策略为 `validated-unused-quotation-pruning-v1`。输入字段仍是 event/appraisal/delta/evidence/links，输出除原有明确评价依据外，新增程序拥有的审计字段：

```json
{"normalizationAudit":{"schemaVersion":1,"policyVersion":"validated-unused-quotation-pruning-v1","receivedQuoteCount":5,"keptQuoteCount":4,"discardedUnusedQuoteCount":1}}
```

此例来自独立脚本样例，不是对被丢弃真实响应的重建。数量由实际通过验证的输入表与引用集合计算，模型给出的同名元数据被忽略；不保存另一份未使用引文表。原事件文字、评价数值、情绪变化和已引用文字不变。

原严格规范化器仍先检查全表唯一、最多五项、每项最多 64 Unicode code points、当前事件逐字连续引用及链接/索引形状。只有它报告 `unused_compact_evidence` 才在副本中按原顺序删除未引用项并重编号，再运行原完整规范化器。其他错误不会靠清理掩盖，后续非零目标、未知占位或情绪依据不合格仍拒绝。无修复模型请求、自动猜链接、补依据、改数值、截断或拼接。

通过仅说明结构及逐字一致；引文语义支持仍未评估，不强制改变情绪、产生启示或正向收尾。旧严格协议仍拒绝相同输入，不能把本候选称为行为完全等价的修改。

## 模拟运行、保存和读取

`src/compact-v2-offline.js` 提供明确要求本地 simulator 的 FakeProvider 子类及 `CompactV2Rehearsal`，复用原 Nightvoyage/Store。没有默认 HTTP、密钥读取或生产传输参数；GatedDeepSeekClient 仍拒绝 v2 selector。固定真实入口的三个协议文件及诊断白名单源码摘要未变，旧账本/价格/权限/恢复门不变。

首次 queued 保存已有新协议及归一化策略身份；执行/恢复核对身份。最多两幕加一次原有逐字醒来摘录。供应商响应仍先经原 400-token/1200-byte 解析守卫；程序审计不是模型输出，不用它虚增响应限额。假运行的请求预算是本地字节估计/调用上限，不能当作真实 token、收费或真实传输结算证据。

保存的每幕保留新版本、明确依据及审计计数。检查点重开时重新校验规范内容，并核对 received/kept/discarded 的范围、等式、与保留依据的唯一数量一致；不把丢弃数量重算成零。由于未保留原始整表，重开时只能验证计数一致性，不能独立重放最初究竟丢弃了哪几段文字。初次生成时程序计算、后续本地受管理存储的信任边界沿用现有合同。

`readAppraisalView` 只为新版本增加规范验证和只读审计字段；无依据项继续显示 not_stated/null，模拟 before/delta/after 单列。原梦、回想/续写、珍藏、余韵和日常召回依旧分开。来源编号/版本、梦境身份与非事实标记随父记录和读取视图保留；模型不能把归一化过程冒充现实记忆。

没有新增缓存、索引、日志或备份。撤回/删除沿用原 Store 清除场景、依据、计数及后代；重开和旧召回不能恢复正文。已经交付到 Store 外的副本、外部备份、服务商及物理擦除仍不在首版自动清除范围。

## 测试和边界

12 项新测试涵盖字段/引用不变与模型元数据无效、检查点幂等/伪造计数拒绝、非法表/后续依据检查、受限请求、旧协议隔离、无 simulator 拒绝、无修复调用、完整假闭环与原梦不被回想覆盖、取消迟到输出、醒来拒绝新事件、撤回/旧召回、实际子进程检查点退出/恢复，以及保存失败不发布。共享读取视图也包含在回归检查中。

首次定向运行 11/12，通过项之外的独立检查脚本因遗漏闭合括号报 SyntaxError；修正后完整 Linux LF 套件 **187/187** 通过。临时 Linux CRLF 副本只跑新候选和既有读取视图的定向测试，不声称重跑全套。两份独立检查脚本均完成三次 fake stage calls、持久化/重开、重复调用零次、读取视图与撤回检查。直接输出及源码摘要见 `docs/validation/compact-v2-offline.*`。

这些是独立虚构脚本、临时外部 Store、明确 simulator 和零真实请求。没有处理用户原失败响应、打开用户梦簿、读取真实密钥或私有材料。同作者复查，不是独立审计。

后续用户提供 Windows / Node.js v24.19.0 的独立脚本结果：completed，三次假调用，成功重开，重复调用零次；两幕 received/kept/discarded 分别为 1/0/1 和 5/4/1。读取视图可用，无依据控制值为 null，撤回后视图为 null，原素材仍不外发，真实请求零次。聚合证据见 `docs/validation/user-local-compact-v2-offline.json`。这是用户本地报告，不是独立机器或精确 checkout 核验；没有报告 Windows 完整 187 项或故障/取消测试套件，不据此补计通过。真实生成质量仍未验收。

后续若需用户本地检查，仅用 `node scripts/check-compact-v2-offline.mjs`，无需 Key。真实集成需单独评审新版本、检查点/计费原子发布和明确试跑范围，并另行取得费用/素材外发决定；**当前没有新付费入口或新试跑授权**。两笔未知预算占用继续保留，不能因此把旧失败改成成功或重试旧请求。Asteria 适配器仍为待对接。

本实现使用本项目 MIT 模块及独立虚构探针，没有第三方实现复制、新依赖或跨仓库修改。
