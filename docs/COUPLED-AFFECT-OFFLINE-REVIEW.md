# 情绪变化与依据同处：离线合同对照

本轮交付独立离线比较器、15 对独立虚构样例、检查脚本及测试。**仍不接入付费客户端或梦境持久化**，不是当前失败响应的修复或重建，没有改旧协议、价格、预算或三个 unknown 占用。候选身份为 `offline-coupled-affect-review-v1`。

## 比较什么

旧结构把 `delta` 和 `links.affect` 放在两个位置。新候选将它们放入一个必填 affect 对象，只接受两个明确分支：

```json
{"affect":{"kind":"unchanged"}}
```

```json
{"affect":{"kind":"estimated","delta":{"valence":-0.05,"arousal":0.1},"evidence":0}}
```

这里 0 是当前场景引文表的索引，不是零变化。完整候选顶层为 event/appraisal/evidence/links/affect；links 只含 goal/control/uncertainty。unchanged 的确切声明编码为两项零变化、空情绪依据；estimated 必须同时给出两项数值和整数引文编号。estimated 也可明确估计为零并保留依据，不把有依据的零值丢弃。

没有省略分支的默认值。unchanged 如夹带 delta 或 evidence 就拒绝；estimated 缺依据、null/字符串/小数编号也拒绝，不推断成 unchanged，不替用户或模型补链接。顶层还带旧 delta 或未知字段也拒绝，避免静默忽略供给的非零变化。只有明确选择 unchanged 且没有冲突字段才编码零，这与对不合格响应强制归零不同。

内部把显式分支映射为已有 v2 字段，运行原完整校验：所有引文含未引用项都须有效、唯一、受限且当前事件连续逐字；合法未引用项仍由原 v2 策略处理。目标/控制/不确定性依据、数字域和情绪依据要求全部不变。映射保留估计的原数值、事件、评价和所引用文字，不创造新依据。比较器仅返回固定诊断、是否规范等价和字节数；不返回或保存场景、引文、情绪数值、模型解释或原表。

## 发现与裁定

15 对脚本涵盖原四个独立虚构场景、缺依据变化、unchanged 冲突、错误索引、未落在事件中的引文、逐字但语义不相关的引文、合法未引用项、原目标/控制守卫、非法数值、null 引用与有依据零估计。七对两侧均接受，最终规范场景及审计完全相同；其余用来确认缺漏和原有拒绝边界。新格式下的缺引用首先作为分支形状错误拒绝；这只是更接近字段组合位置的检测，不证明真实模型会更少遗漏。

| 独立样例 | 旧平铺 JSON bytes | 成对候选 JSON bytes |
| --- | ---: | ---: |
| ordinary-no-goal | 248 | 230 |
| stated-goal-hindered | 441 | 473 |
| stated-goal-helped | 413 | 445 |
| affect-without-goal | 349 | 381 |

这些是 UTF-8 JSON 字节，不是 token 或真实费用；变化场景多 32 bytes，并非普遍压缩。没有证明全部合法组合都能装入原 400-token/1200-byte 限额。更短的 unchanged 分支也可能影响模型选择，尚无数据证明不会压低情绪变化频率。字面引文不相关的样例故意保持结构接受，明确暴露语义验证仍未解决。

**裁定：保留为独立候选，暂不替换 live 协议。** 结构上可以把变化与依据同时列为必填，但真实遵循率改善、语义支持和梦境质量全部未评估。不能把脚本 15 对当作模型成功率，不能用它解释已丢弃真实响应的具体数值或引文。

## 复现与边界

`node scripts/check-coupled-affect-review.mjs` 不需要 Key，只读取公开虚构样例。脚本将 native fetch 替换为拒绝函数并核对零次请求；既有新旧九个源文件 pin 仍通过。候选不能成为 GatedDeepSeekClient selector 或 allowance 协议，没有 HTTP、provider、运行目录、检查点、预算结算、前端或 Asteria 适配器。后者仍待对接。
