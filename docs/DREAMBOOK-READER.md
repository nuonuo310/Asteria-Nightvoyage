# 梦簿：日常本地查看入口

状态：`local_reader_supported / asteria_pending`。新增 scripts/dreambook.mjs，复用既有内容查看与独立评审适配器。入口只看已有梦，不生成、不召回、不写评审，不改原梦、醒来、情绪数值、珍藏/访问策略或账本；没有 Key、费用批准、删除或外发选项。

## 两条日常命令

在仓库中执行：

```sh
node scripts/dreambook.mjs list
node scripts/dreambook.mjs read --latest
```

默认仅打开已有的本地 Nightvoyage/first-fictional-trial Store：Windows 使用 LOCALAPPDATA，其他环境沿用原本本地数据路径。没有 state.json 就停止，不创建新梦簿/账户；help 不读目录。也可以显式 --data-dir 指定绝对、已有、仓外目录，沿用 Store 的符号链接、单 owner 和恢复约束。

list 返回无正文 JSON 目录：梦编号、来源/版本、素材 fictional 与梦境/nonfact 标志、幕数、珍藏/访问设置、保存的协议及 protocolSupported。没有原幕、醒来、联想、情绪引文或评审备注。protocolSupported 只表示该协议分支在既有内容阅读器支持范围，不代表正文或质量已通过。畸形身份/来源拒绝，不能把额外正文藏进来源对象后冒充目录元数据。

read 必须二选一：--latest，或 --dream-id <实际梦编号>。--latest 是当前可见 dream 条目在 Store 持久插入顺序中的最后一条，排除评审/回想/续写；没有创建时间记录就不编造“最新时间”，也不提供会漂移的显示序号作为永久身份。需要固定目标时使用梦的真实 id。来源撤回或原梦删除后，目录不列出它；显式读该 id 返回不可访问。--latest 在这时指向剩下的最后可见梦，含义不会暗中锁到旧目标。

如果被选中的梦协议尚不受支持或正文损坏，读取停止，不悄悄换成更早一梦。旧协议的目录元数据仍可查看，不自动迁移、补写或重签旧批准。当前内容阅读支持 coupled、continuity 与 inline 三个明确版本，其他历史内容可按其原入口处理。

## 阅读分离与私人内容

沿用既有 renderContentReview：先原梦分幕，再醒来残片及初始模拟余韵，再梦中评价与字面依据、已有独立意见。来源版本、梦境身份、非事实标志、评审者与父绑定保持。评审显示不等于人工验收，方向意见不改写原 delta；梦可以安静、无启示、无联想或不安。

只有显式 read 才把私人梦簿正文显示在本地终端；它不建立导出文件或另存正文缓存。文字按 JSON 字符串引用，控制字符不会当终端指令执行。终端副本仍由用户持有，不能因来源后来撤回而远程擦掉。用户验证时可以只回报自检汇总；不要求把梦簿、state.json、实际编号或评审正文贴回公开仓库。

本入口是逻辑只读，不声称整个 Store 生命周期零文件写入：owner 锁、启动日志清除/恢复及原子保存仍可发生。恢复会按既有规则标记中断运行和 unknown；不是本阅读器执行新尝试或更改费用规则。支持范围仍限单机受管理 Store，外部备份、调用者副本、物理擦除及供应商留存不在保证内。

源码位于 scripts，不改任何 src/fixtures/package、付费源码清单/图、合同、批准、额度、占款或期限。没有网络提供商、Asteria 或前端接入。本地查看不用重新获准价格，也不意味着可以重新生成。

## 独立虚构自检

```sh
node scripts/check-dreambook-reader.mjs
```

命令只创建自己的系统临时虚构 Store。3次假生成后保存一条虚构助手意见，经真实阅读器子进程检验：目录不含正文，latest 不选到后写的评审，按 id 和 --latest 均分开显示梦/醒来/意见，原梦/账本/意见数量和稳定 state.json 字节不变；撤回重开后目录与读操作不交付正文。Key/native HTTP/fetch 守卫拒绝意外调用，无用户 Store 访问、真实模型、生成质量判断或 Asteria 兼容声明。

测试另覆盖缺省目录与显式路径、无数据不创建、非法选项、owner 竞争、来源/醒来异常、未支持的最后一梦不替换、删除和错误信息不回显正文。验证记录见 validation/dreambook-reader-validation.json。Linux 的 CRLF 副本不是 Windows 实机；下一步用户先运行同一独立自检，再显式读取自己已有的最近一梦，不为验证而删除或撤回用户梦簿。

项目自有 MIT 独立实现，无新依赖、第三方复制或私有 Continuity 原文。

## 独立意见的中文排版

read 默认按每条意见分别显示：关联幕、评审者/身份、事件关联、愉悦度/唤醒度方向、幅度状态、原始备注、评审编号和替代关系。中文只映射固定状态，不翻译或改写自由备注，不把 compatible 说成正确，也不把个人身份声明当作认证或人工验收。旧意见与修订意见都显示，不暗中只留最后一条。

需要核对来源版本、父幕指纹、请求编号和结构检查等完整字段时：

```sh
node scripts/dreambook.mjs read --latest --review-json
```

此选项沿用原有完整 JSON 评审显示，仅允许 read 使用；目录仍不含正文。两种显示读取同一份经过既有适配器校验的记录，不新建评审、不改变梦/醒来/账本，也不建立缓存。原始备注继续 JSON 引用，换行和终端控制字符保持转义。既有 Store 启动恢复边界不变。

实现为 scripts/dreambook-review-text.mjs 的展示层，不修改 src 或付费合同源码清单。测试覆盖中文状态、原始备注、空意见、独立修订、完整 JSON 对照、参数门禁和静止 Store 字节不变；完整结果见 validation/dreambook-readable-reviews.json。真实用户 Store 未在工作台访问，Windows 显示待用户确认。
