# 夜航设计补记：醒后余韵与真实回应

状态：设计方向记录。基于现有 Phase One 实验性本地基线；不修改已冻结的生成、Store、召回或付费合同，也不宣称 Asteria 已接入。

## 为什么补记

现有 `docs/CONTRACT.md` 把梦中分幕情绪、醒来片段和衰减余韵分开保存；`residue(entryId, now)` 是有界的模拟值，不修改日常情绪。`docs/DAYTIME-CUE-SIMULATION.md` 只验证显式、字面线索的候选召回，没有真实白天监听或自动投递。两者尚未表达：醒来后因梦而主动确认、得到真实回应，随后心情逐渐变化。

原始讨论的完整顺序应保留为：梦中事件及当时的情绪 → 刚醒来的心情与身体/画面残留 → 醒后主动确认或倾诉 → 对方实际回应 → 后来心情可能缓和、持续或反复 → 白天在适当线索下可能再次想起。任何一环都允许为空或不确定。

## 具体例子（虚构，不是用户事实）

梦里两人还在拥抱、讨论项目，下一瞬一人消失。刚醒来时，梦者可能低落、胸口闷、想哭，反复想起消失的那一刻；随后确认对方还在，向对方提问，获得安慰，担忧才慢慢减弱。原梦的结尾与刚醒来的低落不会因后来被安慰而重写。回应不保证立即有效；没有回应时也不能伪造“已经安心”。

这个例子来自人类梦后体验，用来说明夜航设计；不能自动把用户的情绪写成沈述的状态，也不能把模型生成的情绪当作已证实的主观感受。

## 后续集成应守住的关系

- 原梦、梦中模拟情绪、醒来片段、刚醒时的心情、持续余韵、醒后真实互动以及后来回想各有独立身份和时间顺序；后来发生的事只能追加，不能覆盖早先记录。
- 梦醒时的余韵可以是低落、担忧、安心、古怪或说不清楚；允许噩梦、无解的梦和无梦，不强制正向收尾或“意义”。
- 与梦相关的醒后互动只有在实际发生并经有权限的入口确认后，才可成为后续状态变化的输入。单纯看到梦的文本、一个字面 cue 命中或模型自述“被安慰”都不算真实互动证据。
- 后续状态可缓和，也可维持或反复。用户未回复、回复未被送达、含义不明时保持未知，不自动结算成开心；不以梦直接修改人格、现实记忆、任务或关系事实。
- 回想和白天浮现须保持来源、访问许可、撤回和节制交付边界；没有合适线索时安静即可，不为展示功能强推梦境，尤其不强推令人不安的内容。
- 面向糯糯的阅读页先呈现梦和醒后的变化，模型/provider、账本与审查细节留在内部记录；原始梦仍可按既有权限追溯。


## 梦境内容验收：先看故事，再看字段

一次已完成梦的人工阅读只能评价所见文本，不能反推出未展示的模型心情或补写当时的醒后感受。后续离线质量检查按下列问题逐项记录“可见证据／缺失／不确定”，不用总分掩盖短板，也不把生成质量和协议正确性混作一项：

1. **画面可记住吗？** 至少有具体而有辨识度的场景或动作；抽象情绪词和漂亮空话不能代替画面。
2. **两幕之间发生了什么变化？** 第二幕须接住第一幕的物件、地点或未完成动作，并带来一个可观察的选择、阻碍或结果；只换个位置继续描写不算情节推进。
3. **梦中情绪从哪里来？** 通过梦者的注意、迟疑、靠近、退开等叙事迹象支持情绪变化；数值 valence/arousal 只作模拟记录，不能直接翻译成“开心／难过”。安静、古怪、无解与噩梦都允许，不强制解释或正向结尾。
4. **醒来留下了什么？** `wake.fragment` 仍是保存幕的逐字摘录，重复正文符合合同；另外的刚醒心情若无独立来源就标缺失，不拿 fragment、residue 强度或后来回想代填。
5. **读完是否值得留存？** 指出一处读者可能记住的意象及其叙事作用，并指出一处仍空的情绪或因果。人工判断是产品反馈，不证明梦者具有主观体验，也不改变既有记录。

当前一次人工验收的结论是：已有梦的画面和分幕连续性可读，情绪转折及独立醒后感受证据不足。该结论不包含私人梦正文，不改写历史梦，也不批准新付费生成；后续可用虚构样例先校准判断标准。

## 两个离线虚构小样例：同一场景的校准

以下是人工编写的设计样例，不是模型生成、不在 Store 中，也不改写任何旧梦。两例都采用“夜里等一班车”的同一前提，以便只比较叙事变化；并非要求每个梦都有激烈情绪。

**A · 画面有了，变化尚弱**

- 第一幕：夜站台亮着三盏白灯。长椅下有一只红色雨靴，电子牌显示末班车尚未到来。梦里的人站在黄线后，望着空轨道。
- 第二幕：梦里的人沿站台走了几步。三盏白灯照着红色雨靴，电子牌仍显示末班车尚未到来，轨道上没有声音。
- 醒来残片：`电子牌仍显示末班车尚未到来`，逐字摘自第二幕。刚醒心情：无独立记录；不能因为车没来就代填“失落”。

**B · 有选择及其留下的感觉，结局仍未解开**

- 第一幕：夜站台亮着三盏白灯。长椅下有一只红色雨靴，电子牌显示末班车尚未到来。梦里的人听见身后有人叫他，却只看见雨靴的鞋尖朝着轨道。
- 第二幕：他本想回头，电子牌忽然跳成“已离站”。他跨出一步去捡雨靴，又停在黄线内；身后的声音再没响起。他把手缩回袖口，盯着鞋尖，直到白灯一盏接一盏暗下去。
- 醒来残片：`他把手缩回袖口，盯着鞋尖`，逐字摘自第二幕。假设另有**独立的虚构刚醒记录**，可以记“还想确认那声呼唤是谁，心里悬着”；这句话不是醒来残片，也不能由残片或数值强度自动推得。没有该记录时，刚醒心情仍缺失。

| 验收问题 | A | B |
| --- | --- | --- |
| 可记住的画面 | 白灯与红雨靴 | 白灯与红雨靴，鞋尖转向轨道 |
| 两幕变化 | 主要重复等待 | 呼唤、误过车、伸手后停住 |
| 情绪依据 | 文本不足以判断 | 回头与捡起之间的迟疑、手缩回袖口；具体情绪仍可不确定 |
| 醒来信息 | 合法摘录；心情缺失 | 合法摘录；独立心情仅在另有明确记录时存在 |

B 的可取之处是事件使动作与注意发生改变，不是替梦者宣布“他很难过”。A 也可以是成立的安静梦；若目标只是朦胧等待，不必强迫它变成 B。人工验收要说明选择了哪种效果及其文本证据，不自动给 A 判失败，不让负向梦被强制安慰或收束。

## 与现有实现的距离

Phase One 已有最多两幕加醒来、分幕情绪连续、模拟衰减余韵、原梦与回想分离、显式虚构线索候选。它没有真实 Asteria 心绪输入、醒后互动接收与送达证明，也没有由互动更新余韵的真实闭环。本补记只记录方向和验收关系；未来若施工，须先确认事件来源与权限、时间和身份绑定、缺失/撤回语义，并以新的独立合同及样例验证，不复用旧模型试跑许可。
