后续进度：[历史读取分离已实现](HISTORICAL-READ-COMPATIBILITY.md)，当前 proposal 继续检查源码，已存配置可在摘要漂移后读取。本文的阻断复现与待实施表记录当时设计阶段；coupled 门控预算协议及真实入口仍待实施。

本阶段已交付离线字节审查器和可复现测试；预算接入部分是设计，**尚未实现或运行真实预算闭环**。用户报告 Windows/Node v24.19.0 独立模拟脚本 completed、假调用三次、重开/零重复、一个 dream/非事实召回、撤回后候选零/视图 null，两幕声明及审计一致。聚合见 `docs/validation/user-local-coupled-affect-offline.json`。这不是 Windows 完整 252 项或故障测试报告，也不是独立机器/checkout 验证。

## 字节审查结果

离线审查读取 15 个独立虚构候选及六个合成边界，用现有规范器和原响应 parser 分开核对结构与整体大小。模拟 usage 声明输出 400 仅用于进入 parser，不来自模型，不是 tokenizer 计数。所有实际模型 token 数为 null。

| 合成边界 | JSON UTF-8 bytes | 场景结构 | 整体响应 parser |
| --- | ---: | --- | --- |
| ASCII 填充至精确上限 | 1200 | 接受 | 接受 |
| 上限多一字节 | 1201 | 接受 | 拒绝 |
| 五条各 64 code points 的有效引文 | 2198 | 接受 | 拒绝 |
| 引号、反斜线及换行转义 | 1700 | 接受 | 拒绝 |
| 250 个合成 astral 字符 | 1200 | 接受 | 接受 |
| 251 个合成 astral 字符 | 1204 | 接受 | 拒绝 |

边界文本仅用于字面结构测试，不是建议模型生成这样的梦，也未评估语义支持。结果证明单项合法并不能保证所有字段组合装入当前 1200-byte 响应安全上限；不得用字节当 token、按字节估算实际费用或声称 400 tokens 一定够。parser 接受也只代表合成 JSON/usage/大小检查，不代表模型真的生成过它。

当前固定虚构 seed 的首次请求 body 为 4380 bytes。另造五份各 20000 字符的虚构来源，仍可通过 snapshot 结构和离线 request builder，body 达 104478 bytes；这不是获准试跑素材。离线 builder 不实施付费客户端的 65536-byte 请求限制。将来预算客户端必须保留已有客户端在**构建后、reserve/dispatch 之前**的请求大小守卫；未来 CLI 还需在访问 Key 前另行做同等无密钥预检，而不是假设离线闭环已覆盖这个真实传输约束。当前没有因此外发或截断任何内容。

保留 400-token/1200-byte 和未来 65536-byte 硬限制，不自动扩大预算、不剪掉已引用文字、不截断事件或补发修复调用。新生成合同如需进一步限制长度，应明确版本和可接受范围；本阶段没有更改合同或证明所有合法组合均可传输。

## 预算接入前的历史读取阻断

现有 `readPrunedV2Trial` 通过 reviewedConfig → proposal 同时核验当前九个源码 pin，包含 budget-ledger、gated client 和 runtime。扩展这些核心文件会导致源码摘要改变，进而让旧配置的只读校验失败；不能靠替换旧批准文件的 pin 或重建账户来绕过。

此点已在**仓库外副本**用独立虚构配置复现：改动前可读，在复制的 client 文件末尾加无行为注释后，proposal 与旧配置读取均 source_changed。没有修改工作树的 pinned 源码、打开用户 Store、使用真实账户配置或发送请求。该受控探针证明现有读取耦合，不是声称用户当前已遭遇故障。

设计分两层：

1. 历史读取验证已经持久化的批准配置为静态数据：已知合同版本、精确历史 fixture/价格/源码 pin/额度形状及不可变指纹，并核对实际账项。允许在核心升级后查看历史结果和 unknown 元数据；不据此启用执行、不刷新批准、也不动态导入配置指定的代码。
2. 启动新请求必须额外校验当前实现的源码 pin、有效期、模式、来源权限/撤回、字节/调用/金额上限和明确新批准。旧源码 pin 不再匹配时，应给无正文阻断状态，在读取凭据或 reserve 前停止。已完成的只读重放和失败账项查看不应顺带收费。

历史配置仍必须来自固定已评审 profile，不采信任意新 pin、自称 approved、model/endpoint override 或 caller callback；撤回/删除照常覆盖历史正文访问。过期或源码已变可读账目不等于可生成。兼容性改动需先通过测试，再修改新协议预算核心。这份方案尚未落入运行时代码。
