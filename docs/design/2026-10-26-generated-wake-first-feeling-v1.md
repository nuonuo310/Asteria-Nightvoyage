# 醒后文字心情 · 最小设计 v1

状态：DESIGN ONLY。总控设计决定，不是执行包、协议实现或付费许可。
基于 main@249d38ab6eb65aeab3207771062b0e51b962bd4d；参考 #94@79ad750140ca0b0beb48e1b46ffd175ae4433ecd、

## 目标与完成线

让未来一场新梦在原有第三次 wake 调用中，可选地产生一段独立的虚构刚醒心情，
与逐字醒来残片、模拟 residue、后来回想分别保存和读取。
本轮 DONE LINE 是决定字段语义、保存关系、失败行为与后续验收边界；不要求实现。
本设计完成后停止，不自动派工。Phase One 冻结不变。

## 总控选定的最小路线

采用独立新协议与新执行身份，旧 wake()、旧付费入口、旧运行和旧许可不变。
不扩展成通用情绪系统，不改变两幕场景生成，不专门增加一次心情调用。
新协议第三次调用仍看到已保存两幕和 previousAffect；心情是同次模型输出的新虚构叙事，
不是从 fragment、valence/arousal 或 residue 由程序推导的解释。

## 逻辑响应形状（待实现，不是现有 wire）

新 wake 响应保留 fragment、associations、residue，增加 firstFeeling：

- 可省略 firstFeeling：未记录，保持缺席。
- {status:"present", text:"…"}：独立、简短的刚醒叙事。
- {status:"absent"}：明确记为无，不带 text。
- {status:"uncertain"}：说不清，不带 text。

对象须按新版本封闭校验，不接受其他键。present 的 text 应为去空白后非空的 Unicode 字符串，
至多 240 个 Unicode code points；其他状态不得携带 text。上限是产品长度边界，不声称等于 token 数。
省略与 absent 不能相互转换；null、错误类型、未知状态、空文本与超限文本均为无效输出，
不得静默丢弃、截断、编造补值或另发请求。

提示要求：描述虚构梦中主体刚醒时留下的感觉，可含注意或画面残留；不续梦、不解释寓意、
不声称现实用户或模型实际经历身体感受；不虚构已被安慰、已收到回应。
延续主体称谓，不发明性别；允许安静、负向、复杂、不确定或缺席，不强迫积极收尾。
不强制情绪必须由某个数值映射，也不要求照抄梦里的情绪。
fragment 仍须逐字摘录；firstFeeling 的独立措辞不充当 fragment 的引文依据。

## 保存与来源

原梦 scenes、wake fragment 与模拟 residue 保持各自语义。
firstFeeling 保存为独立派生条目：绑定 dreamId/runId、来源版本、独立身份和固定顺序，
明确 materialKind:fictional / isRealityFact:false。
textBasis 必须区分 generated_fictional_wake 与 #98 的 explicit_fictional_record，
内部绑定协议版本、wake attempt 身份；不能把调用方文字记录冒充同次生成结果。
时间由本地提交生成，注明是记录时间，不能冒充主观醒来时刻或事后恢复的精确发生时间。
后来回想只能独立追加；无旧梦迁移、无补写、无覆盖。

#98 的记录/读取语义可作参考，但不得直接调用其会立即 save() 的显式记录 API
拼接到发布之后。需要在新版本中有受控的记录准备路径，校验后加入同一提交；
不直接改 #98，不把它当成已集成依赖。

## 提交、失败和重开

新生成路径须将 wake 结果、独立心情条目、完成状态及对应本地计费提交，
纳入同一受管理的持久化提交；具体与现有预算运行时的接法需在施工前确认。
不能先把 dream 标 completed，再单独补写心情造成部分成功。
省略是合法成功；显式无效 firstFeeling 是阶段校验失败，不降级为省略。
失败沿用真实 attempt 的账务分类：收到无效响应不等于免费或未派发，
不得为了字段失败退还占款、重发 wake 或重开许可。
取消、来源撤回与删除继续阻止晚到发布；重开不再次请求、不重复追加、不使已删内容复活。

## 阅读

顺序：原梦 → 醒来残片 → 刚醒心情（有记录时）→ 后来回想（有记录时）。
省略不生成空卡；absent/uncertain 用轻量文字呈现。
模拟 residue 独立，不用其衰减自动更改刚醒心情文字。
模型/provider 身份保留内部来源，不突出于梦簿主线。
本轮不设计 CSS 或页面资产。

## 后续离线验收范围

仅在总控另行提交施工包后，用虚构输入/假响应验证：
present、absent、uncertain、省略；安静/负向梦；未知字段与各类无效文本；
第三次调用不增次、不自动修复请求；逐字 fragment 保持；
阶段提交前后故障、重开去重、取消晚到、删除/撤回；
原梦及旧账不变；新旧来源可区分；阅读次序与无空卡。
结构测试不宣称语义质量通过，语义评审不宣称主观体验成立。
不得为了新字段提高旧预算、输出限额或复用旧批准；现有输出额度不够时报告而非自动扩额。
