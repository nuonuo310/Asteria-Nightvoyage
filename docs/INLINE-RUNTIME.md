# 直接引文：独立模拟运行器

状态：**offline_runtime_only**。沿用[格式比较](INLINE-EVIDENCE-REVIEW.md)的新直接引文格式，完成两幕、醒来、持久保存、重开与线索召回的独立脚本闭环。只使用已有公开虚构contrast；没有真实模型、凭据读取、用户Store访问或新增费用。现有50个生产pin仍匹配，四笔历史unknown不清算、不改写。

## 运行合同

`test-support/inline-evidence-runtime.js`导出`InlineRehearsal`，必须显式提供进程内simulator，拒绝live、credential和fetch覆盖。它复用项目自有MIT核心；不是第三方代码复制，也不接入Asteria。独立身份为`offline-inline-runtime-v1`，不能用作现有收费协议或allowance。生产`src`、已批准profile和真实入口均不变。

输入继续采用本地文件适配器可归一化的snapshot合同，素材必须虚构，所有来源的modelEgress保持false。内存、背景、情绪、Mind、意图的可用性/权限降级继续由既有合同处理。本轮固定两幕及一次醒来、最多三次fake调用，拒绝调整每次400输出上限。事件返回`event/appraisal/basis/affect`；直接引文必须来自本幕、最长64 Unicode码点，缺失或非法引用不修复，数值及unknown占位规则不放宽。

独立运行身份、格式版本、提示hash、醒来策略和fake预算种类在首次派发前落盘；后续请求验证整个保存前缀，包括before/delta/after及精确依据。第一幕不加分幕连续性候选提示，第二幕才添加；醒来仍必须摘录某一已保存幕的连续原文。梦境、醒来、余韵、待验证联想和回执分别输出，素材虚构与梦境非事实分别标记；空联想合法，不要求启示或正向收尾。

`appraisalView(entryId)`提供独立带来源的只读复制视图，核对父梦、运行身份与保存幕。它不是现有生产评审适配器的兼容声明；本轮没有扩展生产评审写入口。原梦、后来回想与续写继续分开保存，珍藏、日常召回权限和模拟余韵各自独立。未来Asteria适配器仍为待对接，任何梦境联想都只是候选，不改变真实记忆、人格、任务或调用现实工具。

## 中断和存储边界

- 同一请求/会话去重；完成后的重放不重新调用simulator。改变输入或运行身份拒绝重用。
- 中断后只有完整保存幕前缀、且没有多出的已派发或已接收尝试，才能显式`resume`。实际子进程在第1/2/3次派发退出的模糊阶段不补发；一次失败也不隐式修复或新建额度。
- 排队取消不消耗fake调用；进行中取消/超时会发出AbortSignal并忽略迟到正文。保存幕后的取消阻止后续阶段。
- Store必须在源码仓库外，仍受已有单owner、写入失败关闭、原子保存和撤回/删除日志规则约束。撤回清除受管理源正文、梦、衍生记录与召回缓存；重开和恢复不重新暴露。删除原梦也屏蔽衍生读取。
- 四笔历史占额测试完全由项目测试代码独立伪造，合计8812800 micro-CNY；只证明另一路fake运行、撤回、重开不改账本，不是对用户账单的核算。生产历史未打开，旧未知费用没有被退款、释放或重置。
- 保证仅限受管理Store文件和进程读取，不覆盖终端复制、手工导出、外部备份、文件系统历史/物理擦除或供应商留存。没有自动备份服务；含正文副本需由所有者另行管理。

## 核验与限制

无需Key，运行固定命令：

```sh
node scripts/check-inline-runtime.mjs
```

命令自行创建并清理仓库外临时目录，不读取用户梦簿；模拟3次调用、保存重开、去重、来源完整的召回与撤回。guard阻断native fetch和Key读取。结果为`qualityAssessed:false`、`semanticSupport:not_assessed`，不输出脚本梦正文。

新增生命周期25项，联合格式32项及当前真实入口31项，共88/88；临时Linux CRLF副本新增25/25。包含真正进程退出、保存失败、取消/超时、格式拒绝、预算上限、撤回/删除、历史账本不变和独立视图防别名检查。证据见[验证记录](validation/inline-runtime-validation.json)。本轮没有新全仓测试结果或Windows实机验收，先前结果不重标。

fake输入预算为核心payload的UTF-8字节估算，**不包含system提示**；fake输出和simulator usage也不是实际token或货币计量。另对实际序列化请求设置65536-byte硬限，响应继续400声称输出token/1200 JSON bytes校验；这些离线检查不能证明供应商计量、真实费用、模型遵循或梦境质量。共享引文重复仍可能超长，原先1359-byte边界仍拒绝。
